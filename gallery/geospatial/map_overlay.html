Map Overlay with Tiles#

A map overlay showing earthquake locations on top of a tile map.
This example uses tiles=True to render geographic context underneath the data.

import hvplot.pandas  # noqa
import hvsampledata

df = hvsampledata.earthquakes("pandas")

df.hvplot.points(
    x='lon',
    y='lat',
    tiles=True,
    alpha=0.4,
    color='mag',
    cmap='viridis_r',
    title='Earthquake Map Overlay (Bokeh)',
    xlabel='Longitude',
    ylabel='Latitude',
)

Note

Map overlays using tiles=True are only supported in the Bokeh backend. The Matplotlib backend does not support rendering base tile layers or geographic tiles.

To learn more about tiles and geo plotting, see the Points documentation.
